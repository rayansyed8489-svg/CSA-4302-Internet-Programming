Return Book Desk Instructions

When a student returns a book:

  • The system compares the return date against the Expiry Date.
  • If returned past expiry date, fine is automatically calculated at ₹5 / day.
  • Upon clicking "Process Return" below, the book copy is automatically replenished into available inventory.
  • Any unpaid fines are registered in the student's account for settlement.

Library Borrowing Rules

  • Undergraduate students can borrow up to 3 books simultaneously for 14 days.
  • Renewals can be made up to 2 times if no other student has reserved the title.
  • Overdue fines start accumulating immediately from the day after the expiration date at ₹5/day.
  • Digital study materials can be downloaded without limits for enrolled students.
